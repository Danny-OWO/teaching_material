## 0. 程式語言

如果你在看這份教材的時間點還是 20XX 年，電腦應該——我是說應該——還是使用二進位吧。
顧名思義，電腦真正能執行的是 **機器語言（Machine Code）**，也就是由 0 和 1 組成的指令。
而程式語言便可粗略分成：

- **低階語言（Low-level Language）**：更接近電腦硬體，例如 Machine Code、Assembly。執行方式與硬體關係密切，但人類閱讀與撰寫較困難。
- **高階語言（High-level Language）**：更接近人類思考方式，例如 C++、Python、Java。語法較容易閱讀，也能讓我們不用直接操作 CPU 指令。

因此，你寫的 C++ 程式必須先被翻譯成電腦能執行的檔案。負責翻譯的是 **編譯器（Compiler）**。

常見的 C++ compiler 有：

- `g++`：GCC 的 C++ compiler
- `clang++`：Clang 的 C++ compiler
- `MSVC`：Microsoft 的 C++ compiler

如果你現在使用的環境已經有「執行」按鈕，可以先跳過下面這段。在 terminal 中，可以這樣編譯與執行：

```text
g++ -std=c++17 test.cpp -o test
./test
```

## 1. 一個小型 C++ 程式

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a, b;
    cin >> a >> b;
    cout << a + b << '\n';
    return 0;
}
```

輸入 `3 5`，會輸出 `8`。

- `<iostream>` 提供 `cin` 與 `cout`。
- `using namespace std;` 讓我們能寫 `cout`，不用寫 `std::cout`。
- 程式從 `main()` 開始執行，內容放在大括號 `{}` 裡。
- 敘述結尾加上 `;`，註解使用 `//`。
- `return 0;` 表示成功結束；在 `main()` 結尾可以省略。

## 2. 變數與輸入輸出

使用變數前先宣告，拿來計算前先給它值。

```cpp
int count = 10;          // 整數
double height = 2.5;     // 可以存小數的數值
count = 12;              // 改變儲存的值
```

`cin >> a >> b;` 依序讀入數值，輸入之間可以用空白或換行隔開。
`cout << a << " " << b;` 輸出兩個值，中間留一個空白。
`endl` 和 `'\n'` 都能換行；`endl` 還會強制送出暫存的輸出。

### 使用 `string` 儲存文字

`string` 用來儲存文字，使用時要引入 `<string>` 標頭檔。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
    string name;
    cin >> name;
    cout << "Hello, " << name << "!" << endl;
}
```

輸入 `Harry`，會輸出 `Hello, Harry!`。`cin >> name` 一次讀取一個單字。
雙引號內的文字會直接印出；需要空白或標點時，也要寫在引號裡。

## 3. 基本運算

| 運算子 | 意思 | 範例 | 結果 |
|---|---|---|---|
| `+` | 加法 | `10 + 3` | `13` |
| `-` | 減法 | `10 - 3` | `7` |
| `*` | 乘法 | `10 * 3` | `30` |
| `/` | 除法 | `10 / 3` | `3` |
| `%` | 整數除法的餘數 | `10 % 3` | `1` |

當兩邊都是整數時，`/` 會捨去小數部分，不會四捨五入。
`%` 用於整數。除法與取餘數的除數都不能是零。

### 小數除法

```cpp
cout << 5 / 2 << '\n';    // 2：整數除法
cout << 5 / 2.0 << '\n';  // 2.5：浮點數除法
double x = 5.0;
cout << x / 2 << '\n';    // 2.5
```

只要除法其中一邊是浮點數，就會保留小數部分。
先算 `5 / 2` 再存入 `float`，也救不回已經被捨去的小數。

## 4. 更新變數

```cpp
int x = 5;
x = x + 3;  // x 變成 8
x += 2;     // x 變成 10
x++;        // x 變成 11
x--;        // x 變成 10
```

`=` 是存入數值；`==` 是比較是否相等。其他更新簡寫還有 `-=`、`*=`、`/=`、`%=`。

## 5. 運算順序

先算括號，再算 `* / %`，最後算 `+ -`；同一組內的運算由左至右。
`2 + 3 * 4` 是 `14`；`(2 + 3) * 4` 是 `20`。

# 演算法筆記：前綴和（Prefix Sum）與 差分（Difference Array）

前綴和與差分是電腦科學中非常經典的**互逆運算**。簡單來說：
| 方法 | 用途 |
| :--- | :--- |
| **前綴和** |**頻繁查詢** 區間總和。 |
| **差分** |**頻繁修改** 區間數值。 |

---

## ⚖️ 一分鐘核心對比表

| 特性 | 前綴和 (Prefix Sum) | 差分 (Difference Array) |
| :--- | :--- | :--- |
| **主要目的** | **快速查詢** 某個區間的總和 | **快速修改** 某個區間內的所有數值 |
| **核心精神** | 把前面所有數字**「累加」**起來 | 記錄當前數字與前一個數字的**「差值」** |
| **時間複雜度** | 查詢 $O(1)$，修改 $O(N)$ | 修改 $O(1)$，最後還原答案 $O(N)$ |

---

## 🔍 1. 前綴和 (Prefix Sum)

### 💡 核心觀念
新增一個前綴和陣列，使每個元素皆為由開頭到此元素的總和
```text
lst = [1, 7, 2, 4]
```
則我們新增前綴和陣列為
```text
pre = [1, 8, 10, 14]
```
如此一來，每當有人問起前三項和或是第二項到第四項的和時，我們便不需每次都寫一個for去達成，這不僅簡化了過程，更也減少了每次 **$O(n)$** 的時間複雜度至 **$O(1)$**

```text
例如前三項和： pre[2] = 10
例如第二到第四項和：pre[3] - pre[1] = 14 - 8 = 6
```
---

## 🛠️ 2. 差分 (Difference Array)

### 💡 核心觀念
差分陣列的每個格子，儲存的是**「當前數字與前一個數字的差值（變化量）」**。
它是前綴和的逆運算。如果對差分陣列做一次前綴和（逐項累加），就能完美還原出原始陣列。

新增一個差分陣列，使每個元素皆為本身和前一個元素的差
```text
lst = [1, 7, 2, 4, 10, 25]
```
則我們新增差分陣列為
```text
dif = [1, 6, -5, 2, 6, 15]
```
如此一來，每當有人想要將第二項到第四項都加上5時，我們便不需每次都寫一個for去達成。
我們只需在
```text
dif[1] += 5 dif[4] -= 5
```
```text
dif 變為 [1, 11, -5, 2, 1, 15]
```
再利用前綴和還原
```text
pre = [1, 1+11, 1+11-5, 1+11-5+2, 1+11-5+2+1, 1+11-5+2+1+15]
pre = [1, 12, 7, 9, 10, 25] 
```
便達成目的

這不僅簡化了過程，更也減少了 **$O(n)$** 的時間複雜度至 **$O(1)$**

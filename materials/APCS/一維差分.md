# 一維差分陣列

對於這種**頻繁對一個區間進行加／減數值，最後才需要取得完整陣列結果**的問題，可以使用 **差分陣列（Difference Array）**。

---

## 1. 暴力做法

假設給定一個陣列：

```text
[2, 1, 2, 3, 4]
```

現在想要將**第 2 個位置到第 4 個位置全部 +5**。

直接一個一個修改：

```text
[2, 1+5, 2+5, 3+5, 4]
```

得到：

```text
[2, 6, 7, 8, 4]
```

如果區間長度為 `N`，每次都需要逐一修改區間內的元素，因此一次操作最壞需要：

$$
O(N)
$$

如果有很多次操作，整體效率會比較差。

---

# 2. 差分陣列

差分陣列的概念是：

> 將每個元素表示成「當前元素 − 前一個元素」。

也就是：

$$
D[i] = A[i] - A[i-1]
$$

例如原本的陣列：

```text
A = [2, 1, 2, 3, 4]
```

其差分陣列為：

```text
D = [2, -1, 1, 1, 1]
```

計算方式：

```text
2
1 - 2 = -1
2 - 1 = 1
3 - 2 = 1
4 - 3 = 1
```

因此：

```text
原陣列：
[ 2,  1,  2,  3,  4]

差分陣列：
[ 2, -1,  1,  1,  1]
```

---

# 3. 使用 Prefix Sum 還原

差分陣列可以透過 **Prefix Sum（前綴和）** 還原成原本的陣列。

例如：

```text
D = [2, -1, 1, 1, 1]
```

依序累加：

```text
2
2 + (-1) = 1
2 + (-1) + 1 = 2
2 + (-1) + 1 + 1 = 3
2 + (-1) + 1 + 1 + 1 = 4
```

因此得到：

```text
[2, 1, 2, 3, 4]
```

也就是原本的陣列。

---

# 4. 使用差分陣列進行區間修改

現在回到原本的問題：

> 將第 2～4 個位置全部 +5。

原本的差分陣列：

```text
[2, -1, 1, 1, 1]
```

我們不需要真的修改第 2、3、4 個位置。

只需要修改**區間的兩個邊界**：

```cpp
D[2] += 5;
D[5] -= 5;
```

因此差分陣列變成：

```text
[2, 4, 1, 1, -4]
```

---

# 5. 還原成原陣列

接著對新的差分陣列做 Prefix Sum：

```text
2
2 + 4 = 6
2 + 4 + 1 = 7
2 + 4 + 1 + 1 = 8
2 + 4 + 1 + 1 - 4 = 4
```

得到：

```text
[2, 6, 7, 8, 4]
```

正好就是我們想要的結果。

---

# 6. 為什麼只需要修改兩個位置？

假設我們想將區間：

$$
[l,r]
$$

全部加上 `x`。

只需要：

```cpp
D[l] += x;
D[r + 1] -= x;
```

### `D[l] += x`

代表：

> 從第 `l` 個位置開始，之後的元素都多 `x`。

### `D[r + 1] -= x`

代表：

> 從第 `r + 1` 個位置開始，把剛才增加的 `x` 消除。

因此只有兩個位置需要修改。

---

# 7. 核心公式

對區間 `[l, r]` 全部加上 `x`：

```cpp
D[l] += x;
D[r + 1] -= x;
```

如果是全部減少 `x`：

```cpp
D[l] -= x;
D[r + 1] += x;
```

---

# 8. 複雜度

假設：

* 陣列大小為 `N`
* 有 `Q` 次區間操作

### 暴力

每次區間修改：

$$
O(N)
$$

總複雜度：

$$
O(QN)
$$

### 差分陣列

每次區間修改：

$$
O(1)
$$

`Q` 次操作：

$$
O(Q)
$$

最後使用 Prefix Sum 還原：

$$
O(N)
$$

因此總複雜度：

$$
\boxed{O(Q+N)}
$$

# 10. 與 Prefix Sum 的關係

可以把兩者看成相反的操作：

| 技巧               | 作用          |
| ---------------- | ----------- |
| Prefix Sum       | 將原陣列累積成前綴和  |
| Difference Array | 記錄相鄰元素之間的變化 |
| 差分 → Prefix Sum  | 還原原本的陣列     |

一維差分陣列的核心可以簡化成：

```text
區間 [l, r] + x

D[l]     += x
D[r + 1] -= x

最後 Prefix Sum 還原
```
